## 4. Documentation & UX Recommendations for the Repository

The following observations were noted while following the README like a new teammate. They represent minor friction points that can be clarified in documentation.

### 4.1. Specify Python Binary in Quick Start
- **Current README text:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```
  Followed by: *"Use Python 3.11–3.13."*
- **Observation:** On modern macOS machines where Homebrew is installed, `python3` defaults to Python 3.14. Running `python3 -m venv .venv` without explicitly specifying the minor version creates a 3.14 environment. PyTorch 2.x wheels are not yet available for Python 3.14, leading to installation failure.
- **Recommendation:** Change the command line directly to:
  ```bash
  python3.13 -m venv .venv   # or python3.11 / python3.12
  ```
  or add an explicit `python3 --version` verification step.

### 4.2. Include Dev Requirements in Setup
- **Current README text:** Quick Start only mentions `pip install -r requirements.txt`. `requirements-dev.txt` is introduced much later under CI.
- **Observation:** A teammate performing validation checks cannot run `ruff check .` or `pytest` immediately after completing Quick Start.
- **Recommendation:** Update Quick Start to:
  ```bash
  pip install -r requirements.txt -r requirements-dev.txt
  ```

### 4.3. Document Internal Directory Structure of `wikiart_style5_images.zip`
- **Current README text:**
  ```bash
  unzip wikiart_style5_images.zip -d data/
  ```
- **Observation:** For `scripts/validate_wikiart_subset.py data/wikiart_style5` to succeed, the unpacked files must reside at `data/wikiart_style5/<Class>/*.jpg`. If the zip contains top-level class folders directly (e.g. `Baroque/`), unzipping to `data/` creates `data/Baroque/`, causing validation to fail.
- **Recommendation:** Add a short clarification stating that the archive must contain the `wikiart_style5/` root directory.

### 4.4. Modern Git Syntax in Option B
- **Current README text:** Line 68 states `git checkout data/wikiart_style5/subset_info.json`.
- **Recommendation:** Use `git restore data/wikiart_style5/subset_info.json` to follow modern Git practice and prevent accidental branch switching.
